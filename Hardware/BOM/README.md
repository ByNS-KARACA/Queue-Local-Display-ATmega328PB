# Bill of Materials (BOM)

This directory contains the Bill of Materials for the Queue Local Display PCB.

## Contents

- Component reference designators
- Component values
- Manufacturer part numbers
- Package / footprint information
- Quantity information
- Example supplier / LCSC part numbers where available

## Important Note

Manufacturer and supplier part numbers listed in the BOM are provided primarily as reference components.

Equivalent components with compatible electrical specifications, package dimensions, pinout, voltage/current ratings, tolerance, and temperature ratings may be used when appropriate.

Always verify component compatibility before PCB assembly.
